# Nuestro Primer Mes - 1 Mes de Novios ❤️

Una hermosa experiencia interactiva creada con React para celebrar nuestro primer mes de novios.

## 🚀 Cómo publicar en GitHub Pages (Gratis y en 2 minutos)

Tienes dos opciones muy sencillas para que tu página funcione directamente en GitHub:

### Opción 1: A través de la carpeta `/docs` (La más rápida y directa)
1. Sube este repositorio a tu cuenta de GitHub (`git push`).
2. En tu repositorio de GitHub, ve a **Settings** (Configuración) > **Pages**.
3. En **Build and deployment** > **Source**, selecciona:
   - **Deploy from a branch**
   - Branch: `main` (o `master`)
   - Folder: `/docs`
4. Haz clic en **Save** (Guardar).
5. ¡Listo! En 1 minuto GitHub te dará el enlace de tu página (`https://tu-usuario.github.io/tu-repo/`).

---

### Opción 2: Despliegue automático con GitHub Actions
El proyecto ya incluye el archivo `.github/workflows/deploy.yml`.
1. En GitHub, ve a **Settings** > **Pages**.
2. En **Build and deployment** > **Source**, selecciona **GitHub Actions**.
3. Cada vez que hagas un cambio (`git push`), GitHub compilará y actualizará tu página automáticamente.

---
